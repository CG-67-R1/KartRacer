# Substance abuse

In a kart, a changed reaction time is a **safety** problem for other drivers and marshals, not only a health problem for the user. Strict liability: whatever is in the system counts, intent does not.

Bodies: **WADA**, **SAIDS**, **MSA** (Appendix L / Anti-Doping Code). Lists change **every year** — check the current WADA/MSA download. Categories: prescription, OTC, recreational, PEDs.

**TUE:** SAIDS (international standard). Have it **≥ 7 days** before a National-or-higher meeting (retroactive exists but do not rely on it). Example: salbutamol inhaler.

MSA: no WADA-list substance without a TUE. Commissions should plan testing. Suspicion → MSA medical coordinator. **SAIDS can test without telling MSA.** Ban covers compete / officiate / train / assist; titles and records can go. Testing has already happened at kart Nationals.

Tool flag: `tue_before_event_days: 7` in [`data/sporting-msa.json`](../data/sporting-msa.json).
