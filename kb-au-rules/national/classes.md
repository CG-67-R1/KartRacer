# 2026 Class Rules catalog

Machine table: `data/classes.json`. Restrictors: `data/restrictors.json`. State extras: `data/state-overrides.json`.

Weights = kart + driver + kit. Confirm the meeting Supplementary Regulations.

## Pathway (typical Australian club)

**4SS** (sealed Torini, cheap) or **Cadet 9** (Mini Rok + 16 mm) → **Cadet 12** (Mini Rok open) → **KA3 Junior** (KA100 + 22 mm) → **KA3 Senior** or **TaG Restricted** → **TaG 125 / X30 / Rotax 125 / Rok GP** → **DD2 / KZ2**. **KA2** is the faster junior (Rok DVS). **Yamaha** remains a club option.

MicroMax / MiniMax = **social only**. KA4 = **state/club class** in the 2026 book.
