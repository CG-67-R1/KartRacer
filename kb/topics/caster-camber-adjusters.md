# Caster and camber adjusters

Yoke hole axis sets **caster** (side view, off vertical) and **kingpin inclination**. Changing inclination changes **camber** (front view): negative = tops in, positive = tops out. Camber on karts is usually quoted in **mm**.

## Other front angles

- **Toe:** mm per side via tie rods (RH + LH rose joints). Positive = toe-out.
- **Ackermann:** inner tie-rod hole = more Ackermann = inside wheel turns more = quicker turn-in.

Yoke holes are typically **22 mm**. Kingpin **8 mm** (small karts) or **10 mm** (senior). Adjusters are eccentric + spherical so the kingpin can translate without binding. Keep those spheres free and undamaged.

## Sniper vs Pill

| | Sniper (Type 1) | Pill (Type 2) |
|---|---|---|
| Typical chassis | CRG, Praga | Birel, Haase, Intrepid, Kosmic, Parolin, Ricciardo, Tony, others |
| Independence | Caster and camber **independent** | Eccentric circle: **linked** |
| How | Top slider + grub screws (camber); lift into another groove (caster). Bottom hole is "fixed" but still spherical | Eccentric pills top **and** bottom. Arrow opposite the kingpin hole. Dots ≈ 0.5° claimed per half-turn |

Aftermarket kits can convert Pill → Sniper if the yoke is ~40 mm wide with a 22 mm bore.

**Neutral-neutral**
- Sniper: equal grooves fore/aft, slider mid-travel
- Pill: arrows **fore-aft** (top arrow rearward, bottom forward), **same** pills top and bottom

Practical Pill method: **bottom pill = camber** (rarely changed, harder to reach), **top pill = caster** (changed often). Use the **fewest holes of rotation** so camber moves least when you chase caster. Start neutral, fix camber/pressures from tyre temps, then hunt caster. Green → rubbered: reduce caster. Rain: large caster increases are normal.

## Lasers

Use a Sniper V2/V4 (or Kartlaser). Mount on the **stub axle**, not the hub — same place every time, as close as possible to mid-contact-patch. Level the bubbles. V4 rear lasers check twist and **crab**.

"2 mm per block" and "0.5° per dot" are **approximate** and scale with kart width / laser spacing / stub height (Bambino moves more than DD2). Tune to **your** laser numbers.

**Sweep test for equal caster:** ruler on the floor pan, steer L/R, compare laser height. Match within ~2 mm. ~4 mm difference ≈ 1° caster, or the chassis is twisted.

Never change more than one thing at a time. Recheck toe after caster, camber, or ride-height changes.
