# Flags, lights, driving code

Competition Rules Ch 2–3. Flags **≥ 500 × 500 mm**. Lights may replace or augment flags. Night meetings: battery yellow + red at each flag point.

| Signal | Meaning |
|---|---|
| National flag | May start the race |
| Green + yellow chevron | Restart / reform — only before leader completes lap 1 |
| Yellow | Danger. Slow, **no overtake** until the next point not showing yellow. Raise an arm if safe. Failure to slow is serious |
| Green (optional) | All clear; sometimes starts warm-up/practice (often international) |
| Blue | About to be lapped. Hold line, do not impede |
| Red | Session/race stopped. No overtaking. Arm up, reduced speed to the designated area. Clerk/Steward only |
| Yellow + red stripes (vertical) | Surface adhesion change (oil, water). Up to 4 laps or until normal. Sky-point if rain |
| Blue + red double diagonal | Unsporting / specific instruction — obey officials (see Manual) |
| Black + white diagonal | Warning for unsporting driving |
| Black | Report to officials / disqualification path — stop as instructed |
| Black + orange disc | Mechanical issue — leave the track to pits |
| White / last-lap board | Last lap |
| Black + white chequered | Finish. From chequered until Parc Fermé, follow Technical/parc rules |

**Full Course Yellow** exists in Competition Rules Ch 1 Rule 24. WA **must** use it at State Series/Cup/Trophy. SA **may**.

## Driving code (high level)

Flag/light rules are part of the code. Nose-to-rear-wheel and nose-alongside diagrams in the Manual define when a kart is entitled to space. Contact, forcing off, and ignoring yellows are offences under General Rules Ch 8 plus this chapter.

Cadet/Junior: rib protectors mandatory in those classes; neck/chest recommended.
