# 2026 National Competition Rules overview

Karting Australia publishes one **Australian Karting Manual**. Update 1 of the 2026 book is dated **2 March 2026** (59th edition). State Karting Associations publish **State Regulations** that add series formats, extra divisions, and some weights. Supplementary Regulations for a meeting sit on top.

## Manual map (printed chapters)

**General Rules** — standing regs, fees, insurance, circuit/safety, competitions, emergency/injury, officials, offences, penalties, infringement notices, steward hearings, protests, tribunals, appeals, communicable diseases.

**Competition Rules** — general racing, flags/lights, driving code, **licences**, competition levels/structure.

**Technical Rules** — Australian Kart Formula, homologation, fuel, tyres, noise, scrutineering, apparel.

**Class Rules Ch 1–24** — Cadet 9, MicroMax, Cadet 12, MiniMax, KA4, KA3, (Ch 7 deleted), Rotax Junior Max, KA2, X30, Rotax 125, TaG Restricted, TaG 125, DD2, Rok GP, KZ2, Open Performance, Gearbox, Yamaha, Vintage, 4SS, 4SS Super, 4SE, Dirt.

**Appendices** — social karting, teams, intro to karting, dealer trade, 4SS State Trophy, judicial, senior officials, **lightning/thunderstorm**, policies list.

## How to answer a rules question

1. Class / weight / restrictor / tyre → `data/classes.json` + `data/restrictors.json` + `national/classes.md`
2. Licence / age / grade → `data/licences.json` + `national/licences.md`
3. Flag / start / finish / consolidation → `national/flags-driving.md` + `national/competition.md`
4. Fuel / oil / apparel / homologation → `national/technical.md`
5. Protest / fee / penalty → `data/fees-penalties.json`
6. State series or extra division → `states/{nsw|qld|sa|vic|tas|wa}.md` then `data/state-overrides.json`
7. 2026-only changes → `national/2026-changes.md`
