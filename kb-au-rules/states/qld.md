# QLD 2026 State Regulations

V2, 2 April 2026. Overrides: `data/state-overrides.json` → `qld`.

## Meetings

- State Cup **must** offer: Cadet 9, Cadet 12, KA3 Junior, KA3 Senior, TaG 125. Discretionary: KA2, TaG Restricted, Open Performance.
- Constitute a class: **8** entries (Cup) / **6** (Trophy) unless Supplementary Regulations say otherwise.
- 4SS may run at Top Guns and C&D Titles as a **Club** class.
- Formats 1–12 State Series and above-ish; 1–18 Club.

## Extra divisions

**TaG 125 Combined** kg: Fireball 162; X30 / Rotax / Galaxy / Rok GP **172**.

**TaG Restricted Combined:** all engines **170 kg**.

## Queensland Open Performance

Read with Class Rules Ch 17. No supercharging. Combined weight **≥ 170 kg** needs front brakes + rear or dual rear. Club: DD2 and KZ2 may run to their own class weights/tyres.
