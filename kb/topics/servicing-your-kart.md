# Servicing your kart

Read this year’s class regs, SSRs, SRs and circulars before round 1 — wrong tyre rotation is an easy exclusion.

Clean first (air washer or petrol rag). Keep petrol off tyres and coolant hoses.

## Recurring checks

| Item | What to look for |
|---|---|
| Tie rods | Aluminium bends easily; replace if bent. Rose-joint slop with kart on stand, wheels pulled in/out |
| Front geometry | Laser camber/toe even without a crash |
| Hub studs | Torque nylocs every wheel-off; loose nuts egg the holes |
| Throttle cable | Clamp slip, fray at sheath, slide pop-off. Pedal stop so the cable is not guitar-string tight |
| Chassis cracks | Seat-tube welds, column base, behind/under yokes |
| Nylocs | If the bolt enters the nylon by hand, scrap it |
| Chain/sprocket | Hooked teeth, 10 mm slack, alignment, lube when warm |
| Rear axle | Spin hubs off — visible run-out = replace. Confirm bearings aligned first |
| Wheel bearings | Feel each one; grit = bin |
| Carb | Clean orifices with fuel + air at least once on race day; jets tight |
| Plug | Colour, gasket, gap, torque, clean ceramic/boot |
| Power valve | Scotch-Brite carbon, central, free slide, bellows OK |
| Clutch | Cracks, legal dims, dry drum face, spare needle grease, O-ring back |

Then self-scrutineer against the official list before you join the queue.
