# Era-1996 vs modern CIK

Use era-1996 notes for **symptoms and one-change discipline**. Use current regs for **numbers**.

| Topic | Era-1996 US sprint/oval/dirt | Modern CIK starting point |
|---|---|---|
| Cold pressure | 20 psi rear / 15 psi front | ~1.0 bar class-tyre start (`tyre-setup`) |
| Weight | Record corners; 10 lb lift split as a square check | ~43% F / 57% R, 50/50 L-R |
| Rear track | Wider = looser rear; narrower = more rear stick | Same direction; also axle stiffness and 950 vs 1050 |
| Inside rear | Unload / lift to kill live-axle scrub | Same — required to turn |
| Stagger | Asphalt ≤ ¼"; oval/dirt inches | Usually pair circumferences; stagger is a dirt/oval tool |
| First fix for push | Front pressure, widen rear, fronts in, seat forward | Failing end first; jacking / caster / RH / axle (`handling-troubleshoot`) |
| Hop | Move outside-rear out; more rear pressure | Often **too much** grip — softer axle, drop bar/struts |
| Torsion bar | Flat = soft rear, vertical = stiff | Same idea |
| Dirt slide | Wanted in stock 4-stroke to hold rpm | Confirm class; CIK asphalt is usually plant, not pitch |

**Do not** copy spindle-spacer or WKA nerf-bar stories onto a current Rotax/Rok kart without checking the homologation and SR.
