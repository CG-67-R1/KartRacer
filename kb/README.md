# Kart knowledge base

Internal technical notes and machine-readable numbers for tools and GPT ingest.

Confirm class regs before racing any number. Topics tagged `era-1996` are historical US sprint/oval — do not mix those PSI/stagger values with modern CIK starts.

Australian **National Competition Rules and state regulations** are a separate KB: [`../kb-au-rules/`](../kb-au-rules/).
