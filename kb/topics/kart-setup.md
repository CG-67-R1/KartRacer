# Kart setup

A kart is a flexible tube frame with a **live axle** (no differential). It turns properly only when the **inside rear tyre lifts** on entry so the outside rear can drive around the corner. If the inside rear stays down, the kart **pushes** (understeer).

Work on the end that is failing first. If adding front grip does not fix understeer, then remove rear grip. One change at a time. Confirm the problem is not the driver before rewriting the chassis.

## Starting points

**Weight:** ~43% front / ~57% rear, 50/50 side to side.

**Normal dry grip**
- Front ride height: lowest
- Rear ride height: higher than front (wedge)
- Tyres: ~1.0 bar (see tyre-setup)
- Toe-out: 0–3 mm (smaller motors toward 0)
- Camber: 0–2 mm negative per side
- Caster: central / neutral, then tune from driver feedback
- Side-pod bars: loose in the chassis, bolts tight
- Seat: standard mounts; struts on if class allows

**Low grip / green**
- Raise front and rear ride height
- Medium–stiff axle
- At least two seat struts per side
- Rear torsion bar in, flat as a start
- More caster

**High grip / rubbered-in**
- Lowest rear ride height (axle in highest hole)
- Soft axle
- Loosen or remove seat struts
- Remove rear torsion bar
- More negative camber
- Less caster as grip comes up; more as tyres wear

## Adjustment effects (short)

| Change | Typical result |
|---|---|
| Widen front track | More jacking, more front bite, faster turn-in |
| Narrow front track | Slower turn-in, more push |
| More toe-out | Faster turn-in, more drag, less top speed |
| Toe-in | Rarely used |
| More Ackermann (inner tie-rod hole) | Quicker steer, more inside-rear lift |
| More caster | More front bite, more jacking, more entry rotation |
| Less caster | Easier steer, frees the kart in high grip |
| Raise front ride height | More front (and some rear) transfer / grip |
| Narrow rear track | More rear grip, less stable |
| Widen rear track | More stable, less rear grip |
| Stiffer axle | More rear grip (1050 / high power) |
| Softer axle | Frees chassis; inside rear stays up longer |
| Raise rear ride height | More rear grip |
| Seat struts on / tight | More rear bite |
| Side-pod bars tight | More side bite |
| Higher tyre pressure | Come in faster; too high shrinks contact patch |

Tyre pressure window cited: **0.8–1.5 bar**.

## Power wasters

Brake-pad drag, tight wheel bearings, bad alignment, misaligned engine/sprocket. If turning the wheel loads the motor, the chassis is **bound**.

## Hop vs chatter

- **Violent hop (often tall drivers):** CG too high / rear too stiff. Lower ballast and seat, soften rear, lower rear ride height.
- **Tyre chatter:** tyre letting go (often green). Raise rear pressure, add rear grip.

## Gearing note

Do not hide a handling problem with extra rear teeth. Wet + rain tyres: **+3 or more** rear teeth; remove teeth as the track dries.
