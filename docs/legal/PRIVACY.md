# KartRacer Privacy Policy

**Last updated:** 25 September 2026

KartRacer (“we”, “the app”) is a kart-racing companion from **Motorsport Is Life**.

## Data stored on your device

Stored locally (AsyncStorage / device storage), not uploaded to a KartRacer account:

- Onboarding answers (favourite kart/driver, activity, nickname, avatar)
- Kart photo and avatar face photo
- Day setup sheet and session history
- Track Walk notes and photos
- Trivia score

Export or delete from **Profile & settings → Your data & privacy**.

Storage keys use the `@kartrace_*` prefix so RoadRacer motorcycle profile data is not reused.

## Data sent to our API / AI providers

When a KartRacer API exists, AI chats you send may be processed by the configured LLM provider. Chat history is not kept on our server after the reply. Hosted API is not live yet.
