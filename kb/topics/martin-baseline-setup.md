# US sprint baseline (era-1996)

## Why a baseline

Every good team can return to a known setup when the current one is lost. Record the kart **as it is** before you start changing it. Do not tear a decent-handling kart down to a bare frame for a tenth. Small changes, written down. The **stopwatch** beats seat-of-the-pants.

Start from a bare frame only for a new build, a respray, or post-crash repair. New drivers should live with the current setup until they can feel what the kart is doing.

## Cheap alignment checks (no surface plate)

Park on a flat level surface. No odd ballast hanging on the frame.

1. **Lift each front wheel** with a hanging scale (or feel). Lift weights should be within about **10 lb** of each other.
2. Steer left: right-front should unload. Steer right: left-front should unload. Same ~10 lb window. **Not true** for LTO / offset chassis.
3. **Wheelbase both sides:** left kingpin to rear-axle centre vs right kingpin to right-side axle centre. They must match or the frame is crabbed / badly welded.

If it still will not handle, strip it — cracked welds and ovalled bearings are common finds.

## What to write down

Driver in the seat. Era **scale-session** inflation for that era: **20 psi rear / 15 psi front**. That is **not** a modern Rotax/CIK race pressure (see `tyre-setup`).

Record:

- Four corner weights → front/rear and left/right bias
- Wheelbase (front-to-rear wheel centres)
- Front and rear track (tyre-centre to tyre-centre)
- Toe
- Circumference of each tyre (stagger)
- Wheel-half offset (inside of tyre to mounting flange)
- Rear hub position: hub to frame bracket (not to the bearing flange)
- Seat: back-lip height vs axle, lip fore/aft of axle centreline; front lip vs nearest cross-member; seat-to-ground or rail clearance; strut locations and tilt
- Front: kingpin spacing, kingpin-to-front-rail both sides (offset), spacer stack (do not just count spacers), spindle height in the carrier, caster, tie-rod hole used

Repeat measurements the same way every time or the log is worthless.

## Shop discipline

Manufacturer setup sheets beat a generic book if you can get them (even as a second owner). After any incident, surface-plate the chassis. A sprung or tweaked frame will fake every other adjustment.
